# Sudipta Karmaker — Personal Portfolio

A responsive personal portfolio website built with HTML5, CSS3, JavaScript and Bootstrap 5.3.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Replace your information
Edit `index.html` and update:
- Email address
- Facebook / LinkedIn links
- Any future project details

The form currently performs front-end validation only. Connect it to Formspree, EmailJS, a backend, or another form service before using it for real submissions.
